- **毒の原則**: 系内部と系外部の責務を逆転させると毒を食べたのと同じ結果

- **事業のブラックボックス球**: 資本 Input → 純利益 Output の単純な球に丸め込む
- **ブラックボックスの許容**: 系内部を研究せず、推論で予測可能性を実現する
