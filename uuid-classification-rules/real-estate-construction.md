# 不動産・建設業 — UUID 採番分類ルール

空間・資産が中心であり、購入者・賃借人が利用者となる業種。建設業では**工事発注ロット**に基づく動員管理が中核となる。

## 業種の特性

- **中心となる価値**: 空間（土地、建物、区画）、資産（設備、重機）
- **計測の主体**: 購入者、賃借人（契約、収益、利用状況）
- **建設業の動員**: 工事受注時に発注ロットIDが決まり、**動員オブジェクト**（建設設備、人員、資格、車両、材料の組み合わせ）が割当される。各オブジェクト・イベントに v4/v7 を付与

---

## 動員フローと採番

```
工事受注 → 発注ロットID 発行
    ↓
動員オブジェクトの決定（発注ロットIDに基づく）
    ├── 建設設備 (v4 + v7)
    ├── 人員・作業者 (v4 + v7)
    ├── 資格 (v4 + v7)
    ├── 車両 (v4 + v7)
    └── 材料 (v4 + v7)
    ↓
イベントごとに v4 + v7 付与
```

## Object（対象）の採番

| 対象 | v4 | v7 | 採番なし | 理由 |
|------|-----|-----|----------|------|
| 土地（筆・区画） | ✓ | — | | 資産の基本単位。取引・評価の対象 |
| 建物 | ✓ | ✓ | | 資産の主体。竣工・改修の時系列検索が必要 |
| 区画・ユニット（戸室） | ✓ | ✓ | | 賃貸・販売の単位。契約履歴の検索が必要 |
| 建設設備・重機 | ✓ | ✓ | | 動員オブジェクト。稼働・メンテの時系列が必要 |
| 作業者個人 | ✓ | ✓ | | 動員オブジェクト。人員配置・資格・技能の管理対象 |
| 資格 | ✓ | ✓ | | 動員オブジェクト。作業者・工事の要件 |
| 車両 | ✓ | ✓ | | 動員オブジェクト。稼働・配置の管理対象 |
| 材料 | ✓ | ✓ | | 動員オブジェクト。発注・消費の管理対象 |
| 建設プロジェクト | ✓ | ✓ | | 工事の管理単位。進捗・発注の時系列が必要 |
| 発注ロット | ✓ | ✓ | | 動員の組み合わせを決定する単位 |
| 契約（売買・賃貸） | ✓ | ✓ | | 収益認識のトリガー。契約期間の検索が必要 |
| 購入者・賃借人 | ✓ | ✓ | | 収益の主体。契約・利用履歴の検索が必要 |
| 施工業者・発注先 | ✓ | — | | 発注・支払の管理対象 |
| 設備の部品 | ✓ | — | | BOM・メンテの対象 |

## Morphism（射）の採番

| 射の種別 | 例 | v4 | v7 | 採番なし | 理由 |
|----------|-----|-----|-----|----------|------|
| **Relationship** | 建物-区画、設備-設置場所、契約-区画 | ✓ | | | 資産構造・契約構造 |
| **Relationship** | 発注ロット-動員オブジェクト（設備、人員、資格、車両、材料） | ✓ | ✓ | | 動員の組み合わせ。イベントごとに v4+v7 |
| **Action（収益関連）** | 契約締結、入居、退去、売買成立 | ✓ | ✓ | | 収益認識のトリガー。時系列検索が必要 |
| **Action（非収益）** | 入居者による入退室記録、設備稼働 | | ✓ | | 時系列・分析用 |
| **Event（監査）** | 入居者確認、点検実施、工事完了 | ✓ | ✓ | | 建設業ではイベントごとに v4+v7 |
| **Event（BIM）** | モデル更新、衝突検知 | | ✓ | | 時系列で扱う |
| **Attribute** | 面積、階数、用途 | | | ✓ | 属性値として格納 |

## 建設業：工事受注とイベント

工事が受注された場合、**イベントごとに UUID v4 と UUID v7 の両方**が付与される。

| イベント種別 | v4 | v7 | 備考 |
|--------------|-----|-----|------|
| 工事受注 | ✓ | ✓ | 発注ロットID 発行。動員の起点 |
| 動員決定 | ✓ | ✓ | 発注ロットに基づきオブジェクト組み合わせを確定 |
| 工程開始・完了 | ✓ | ✓ | 進捗・検収の記録 |
| 人員配置・設備投入 | ✓ | ✓ | 動員オブジェクトの割当記録 |

**動員オブジェクト**（建設設備、人員、資格、車両、材料）は、それぞれに v4 + v7 が付与されている。発注ロットIDに基づいて、どのオブジェクトを動員するかが決まる。

## 賃貸管理特有の採番

| 対象 | v4 | v7 | 採番なし | 理由 |
|------|-----|-----|----------|------|
| 賃借人 | ✓ | ✓ | | 収益の主体。契約・利用履歴の検索が必要 |
| 入居者（世帯メンバー） | ✓ | — | | 在籍管理の対象。 |
| 入居者（一時訪問者） | | | ✓ | 記録の主体にならない。 |
| 管理員・清掃員 | | | ✓ | 運用変数。ビジネス分類の軸にならない場合 |

## イベント発行の例

### 建設業

| イベント | 対象 (v4) | 記録 (v7) | 備考 |
|----------|-----------|-----------|------|
| 工事受注 | プロジェクトID、発注先ID | 受注イベントID | 発注ロットID 発行。動員の起点 |
| 動員決定 | 発注ロットID、設備ID、作業者ID、資格ID、車両ID、材料ID | 動員イベントID | オブジェクト組み合わせの確定 |
| 工事完了 | プロジェクトID、発注ID | 完了イベントID | 検収・支払のトリガー |
| 人員配置 | 作業者ID、プロジェクトID | 配置イベントID | 動員オブジェクトの割当 |

### 賃貸・不動産

| イベント | 対象 (v4) | 記録 (v7) | 備考 |
|----------|-----------|-----------|------|
| 契約締結 | 契約ID、区画ID、賃借人ID | 契約イベントID | 収益認識のトリガー |
| 入居 | 契約ID、区画ID | 入居イベントID | 鍵交付・在籍開始 |
| 退去 | 契約ID、区画ID | 退去イベントID | 鍵返却・在籍終了 |
| 設備点検 | 設備ID、区画ID | 点検イベントID | 監査・メンテ履歴 |
| 建物竣工 | 建物ID | 竣工イベントID | 資産の稼働開始 |

---

## 採番なしの扱い

| 対象 | 扱い |
|------|------|
| 管理員・清掃員（賃貸管理） | 運用上の「誰が」は属性。動員対象でない場合は v4 は付与しない |
| 一時訪問者 | 入退室記録のみ。主体として v4 は付与しない |
| 中間的な計算値 | 評価額の試算など。永続化しない |
